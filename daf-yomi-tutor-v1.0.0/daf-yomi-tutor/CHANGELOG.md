# Changelog

All notable changes to Daf Yomi Tutor are documented here.

## 1.0.0 — 2026-08-30

First public-ready release.

### Added
- Guided Daf Yomi lesson structure with Mishnah, sugyot, Rashi/Tosafot, halacha, Aramaic, key takeaways, and review.
- `short`, `deep`, `halacha`, `beginner`, and `advanced` modes.
- Relative dates, explicit dates, and inclusive catch-up ranges.
- "Where are we?" perek/yesterday context and tomorrow preview.
- Special-day notices.
- Masechet completion countdown and siyum planning, including exact completion dates within 14 days.
- Hebcal and Sefaria grounding without API keys or an MCP requirement.
- Optional outside shiur links.
- Source links on demand.
- Verification/failure-state rules.
- Acceptance-test checklist.
